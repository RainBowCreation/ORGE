## Root cause (one line)
Under-filled water has χ=0 ⇒ EOS `p=0` for ANY fill; the emergent `p_dyn` is velocity-divergence-driven and
gravity gives mass-independent velocity ⇒ two lone floor cells (1000 & 500) build identical `p_dyn` ⇒ no
horizontal gradient ⇒ no leveling. SCENE2's dam-break also needs a horizontal cross-species water→air mover
(today `crossOccluded` no-flux + vertical-only swap block it).

### Task 2 — Free-surface head (fixes SCENE 1; helps SCENE 2 finish)
Add a LOCAL, mass-dependent free-surface hydrostatic head to the pressure scalar for incompressible liquids
(χ≈0), own-state only, in ENCRYPT:
```
φ      = clamp(mass/m_rest, 0, 1)
p_surf = c_head · ρ_rest · g · φ · Δy        # ρ_rest = m_rest/V ; start c_head=0.5, tune by test
```
It enters the total pressure `P = p_dyn + p_eos + p_surf` used by the EXISTING open-face pressure flux
(`engine_b.hpp:769`). KEY PROPERTY: for FULL cells `p_surf` is a constant ⇒ cancels in every gradient ⇒
§J.5/rest/flat-pool unaffected; only PARTIAL cells get a lower `p_surf` ⇒ the horizontal leveling driver.
Make SCENE 1 GREEN; promote it to CHEAP. ALL of these stay GREEN (regression gate): cheap 23/23 incl.
`engine_b_stage2_leveling_test` (connected U-shape + flat-pool), `engine_b_stage1_rest_test`,
`engine_b_resolve_test`, `engine_b_yield_gate_test`, `engine_b_eos_test`, conduction, conservation, swap.
Conserve EXACT (grand+per-species). If full-`P` destabilizes the vertical free surface (T2b), fall back to
applying `p_surf` on horizontal faces only, and document. If no stable formulation → escalate.
**Reviews:** spec-compliance + code-quality + **adversarial conservation/hydrostatic-stability**.
